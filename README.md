# Тренировочный тест — 527 вопросов

Статический HTML/CSS/JS-тест на основе выгрузки Moodle.

## Возможности

- 527 вопросов: одиночный и множественный выбор.
- Режим **Тест**:
  - показывать правильность сразу;
  - показать результаты только после завершения.
- Режим **Ответы сразу** — правильные варианты видны с самого начала.
- Итоговый счёт, процент, число ошибок и пропущенных вопросов.
- Разбор вопросов после завершения.
- Навигация по всем 527 вопросам.
- Адаптивный интерфейс для ПК и телефона.
- Автосохранение в `localStorage`: прогресс переживает перезагрузку страницы/устройства и удаляется только кнопкой **«Заново»**.
